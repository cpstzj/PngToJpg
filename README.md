# png2jpg

把 PNG 批量转成 JPG 的 Windows 桌面应用：拖入文件或文件夹，镜像目录结构，可配质量、背景、
命名、冲突策略与并发；转换中可停止，失败行能看原因。

**下载最新版**：https://github.com/cpstzj/PngToJpg/releases/latest

## 下载哪个？

| 文件 | 适合谁 | 说明 |
|---|---|---|
| `png2jpg-x.y.z-setup-x64.exe` | 长期使用 | 安装到当前用户（`%LOCALAPPDATA%\Programs\png2jpg`），生成开始菜单 / 桌面快捷方式，可在「设置 → 应用」卸载 |
| `png2jpg-x.y.z-portable-x64.exe` | 免安装 / 换机 | 双击即用；每次启动自解压到 `%TEMP%`，设置仍保存在 `%APPDATA%\png2jpg` |

两个版本功能相同；设置、日志与「最近使用」在两者之间共享。

## 第一次运行

- 需要 **Windows 10 / 11 x64**（不支持 32 位与 ARM）。
- 安装包**未签名**，SmartScreen 可能提示「未知发布者」：点「更多信息 → 仍要运行」。
- 便携版首次启动会先解压约 10 秒，期间重复双击不会开第二个窗口（单实例锁只会聚焦已有窗口）。
- 不修改、不删除源 PNG；是否覆盖同名 JPG 由「冲突策略」决定。

## 能做什么

- 批量转换 PNG → JPG，支持多选文件 / 整个文件夹（递归），保持相对目录结构
- 质量 1–100、透明背景（白 / 黑 / 自定义色）、EXIF 方向、目标目录
- 命名：保持原名 / 正则模板（`$1` 反向引用、`{n}` / `{n:N}` 序号）/ 自定义单文件名
- 同名冲突：自动编号 / 覆盖 / 跳过；转换前可预览目标文件名
- 转换后预览、失败原因（可复制）、撤销 / 重做、停止（已开始的图片写完再停）
- 中文 / English、暗色主题、键盘操作与读屏标签、设置自动保存
- 单实例；日志与崩溃信息落盘，便于反馈
